✉Mail Access

Effective 23 October 2026

Privacy policy

This policy describes the private Mail Access Windows desktop installation, including its existing OAuth application label Taviro Inbox 726. The operator connects only mailboxes they control or are authorized to use.

Access and purpose

After explicit Google OAuth consent, Mail Access uses the Gmail read-only permission to verify the mailbox address and search and read Microsoft security-code messages. The application correlates a message with the current sign-in request before using its code. The permission technically permits reading Gmail messages; the application's implemented workflow searches for relevant Microsoft security messages. It does not request Gmail sending, editing or deletion permissions.

Local processing and storage

Mail Access processes messages on the operator's Windows computer. It stores OAuth refresh credentials and account data locally using Windows DPAPI tied to the current Windows user. Local working records can include mailbox addresses, message identifiers, receipt timestamps and code-use counters. Sign-in codes are handled during the active sign-in workflow; token, password and code values are excluded from the application's diagnostic journal. Data and any operator-created backups remain under the operator's control.

Data transfer and sharing

The desktop application connects directly to Google's OAuth and Gmail services. A matched Microsoft sign-in code is submitted to Microsoft's sign-in service for the authorized account. This informational website has no mailbox backend and receives no mailbox contents, authorization tokens or sign-in codes from the application. Gmail data is not sold, used for advertising or provided for training generalized AI models.

Mail Access's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control and retention

Connected credentials remain on the computer until the operator replaces or removes the local connection data. Google can also expire or revoke a grant. The operator can revoke the application's access from Google Account connections. Revocation prevents further authorized API access; local records and backups are managed separately by the operator.

This website

These are static informational pages. They contain no analytics scripts, forms or application sign-in. The hosting provider, GitHub Pages, processes ordinary web-request information under the GitHub privacy statement. Visiting these pages does not connect a Gmail mailbox.

Contact and updates

Contact the operator through the Mail Access information repository or the support email displayed on Google's consent screen. Do not include passwords, codes, tokens or private message contents in a public issue. This page will be updated when the described data practices change.
