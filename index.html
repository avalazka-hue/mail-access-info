✉Mail Access

Private Windows desktop application

Your mail access,
on your computer.

Mail Access helps its operator manage authorized access to their own Microsoft mail accounts. With explicit permission, it reads Microsoft sign-in code messages from connected Gmail mailboxes and uses the matching code to complete the operator's sign-in.

Why Gmail access is requested

The application requests gmail.readonly to identify the connected mailbox and search and read relevant Microsoft security-code messages. It uses each code only for the corresponding sign-in request. This permission does not allow the application to send, edit or delete Gmail messages.

A desktop workflow

The application runs on the operator's Windows computer. Gmail authorization is performed through Google OAuth. Tokens are stored locally using Windows user-bound encryption. This website is an information page and does not receive mailbox contents, sign-in codes or tokens.

Personal use

This installation is used privately by its operator with accounts they control. It is not a public service or a sign-up portal. An existing OAuth application label for this installation is Taviro Inbox 726.
